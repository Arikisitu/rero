## ✦ About Rero

Rero is a personal speaking diary built to make daily English practice feel natural, simple, and sustainable.

Instead of memorizing endless vocabulary lists, open Rero, talk about your day, express your thoughts, and learn from the way you communicate.

Turn everyday conversations with yourself into meaningful progress.

## ◈ Features

| Feature | Description |
|---|---|
| 🎙️ **Speaking Diary** | Record your thoughts and reflect on your day through speech. |
| 📝 **Live Transcription** | Turn recognized speech into text as you speak. |
| ⏸️ **Continuous Recording** | Take natural thinking pauses and finish your session when you're ready. |
| ✨ **Grammar Insights** | Review grammar suggestions and improve your expression. |
| 💬 **Expression Learning** | Discover useful conversational expressions from your entries. |
| 📚 **Personal Timeline** | Revisit past speaking sessions and listen to saved recordings. |
| 🔥 **Daily Streaks** | Build a consistent speaking habit and track your activity. |
| 📱 **Android Experience** | Native recording support through Capacitor and Android services. |

## 🎧 The Rero Experience

**01 — Speak**

Talk naturally about your day, your goals, your experiences, or anything on your mind.

**02 — Reflect**

Review your transcript and explore grammar suggestions and useful expressions.

**03 — Improve**

Build a personal timeline of your progress and keep showing up every day.

**04 — Repeat**

Small, consistent speaking sessions can help you become more comfortable expressing yourself.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git
- Android Studio and Android SDK for Android builds
- JDK 17 for the configured Android build environment

### Run locally

```bash
git clone https://github.com/Arikisitu/rero.git
cd rero
npm install
npm run dev
```

### Run checks

```bash
npm test
npm run lint
```

### Build for Android

```bash
npm run build:android
npx cap sync android
```

Then open the `android` directory in Android Studio, or build a debug APK from the Android project using Gradle.

The APK is typically generated at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

*Native builds require a correctly configured Android SDK and Java environment.*

## 🔒 Privacy & Transparency

Rero is designed as a personal speaking diary. Review the source code and app permissions to understand how recording, transcripts, and stored entries are handled.

- Microphone access is required for speaking sessions.
- Speech recognition availability and accuracy depend on the device and configured recognition service.
- Review the application's storage and backup behavior before recording sensitive information.

Do not assume all processing is offline unless the relevant implementation and recognition provider have been verified.
